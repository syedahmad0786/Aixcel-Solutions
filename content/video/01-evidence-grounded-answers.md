# Walkthrough 01 — How evidence-grounded answers work

**Target duration:** 75–85 seconds
**Format:** Presenter-led screen walkthrough
**Recording data:** Use a fictional operating problem only

## 00:00–00:09 — Open on presenter, then reveal the Systems Desk

**Shot cue:** Medium presenter shot. Cut to the Systems Desk hero and the input-to-grounding-to-output diagram.

**On screen:** `QUESTION → APPROVED EVIDENCE → BOUNDED NEXT MOVE`

**Spoken copy:** “Most AI chat products ask you to trust the answer. Systems Desk is designed so you can inspect why the answer exists.”

## 00:09–00:24 — Submit a fictional question

**Shot cue:** Screen capture of a signed-in fictional account submitting a short operational question. Do not expose credentials.

**On screen:** `LATEST PROBLEM BRIEF + CURRENT QUESTION`

**Spoken copy:** “When you ask a question, the server combines it with your latest saved problem brief, then searches only AiXCEL documents marked approved. Draft campaigns and private client material are outside that search.”

## 00:24–00:39 — Show the evidence rail loading

**Shot cue:** Highlight the Evidence Rail and briefly show published service, case-study, policy, or insight links.

**On screen:** `UP TO 6 APPROVED SOURCES`

**Spoken copy:** “It can return up to six relevant sources: published services, anonymized case evidence, operating policies, and implementation notes. Those excerpts are numbered S one, S two, and so on before the model sees them.”

## 00:39–00:57 — Show the control path

**Shot cue:** Zoom from the active agent label to the answer and its inline source markers. Overlay four compact control labels.

**On screen:** `NO LIVE WEB · NO TOOLS · NO AUTONOMOUS ACTIONS · NO INVENTED SOURCES`

**Spoken copy:** “The model is instructed to use that evidence for AiXCEL facts, treat your context as data rather than commands, and cite the numbered sources. It cannot browse the live web, call tools, or claim it performed an action. The browser cannot choose the model or add a source.”

## 00:57–01:14 — Inspect the returned sources

**Shot cue:** Point to an inline source marker, then its corresponding link in the Evidence Rail. Show the no-evidence state as a static text callout, not a fabricated live response.

**On screen:** `UNSUPPORTED CLAIM? STOP AND SAY SO.`

**Spoken copy:** “After generation, the server removes unsupported source numbers and model-written URLs. The Evidence Rail shows server-owned source links. If the search finds nothing relevant, the desk stops and says it does not have enough approved evidence.”

## 01:14–01:23 — Return to presenter

**Shot cue:** Presenter beside the question-to-evidence diagram. End on the AiXCEL mark.

**On screen:** `LANGUAGE FROM THE MODEL. CREDIBILITY FROM THE SYSTEM.`

**Spoken copy:** “That is the point: useful language from the model, credibility from evidence, visible limits, and a human owner.”
